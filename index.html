SDroiMod Save Inspector

Inspecciona archivos locales. El formato de exportación .sdroimod ya está identificado como un ZIP con entradas de guardado cifradas; esta versión puede revisar el contenedor, pero todavía no descifra ni modifica los slots.

Privacidad: el archivo se procesa en esta pestaña; no se sube a GitHub ni a ningún servidor. No cierres la pestaña hasta descargar una copia de respaldo.

1. Abre una copia del guardado

Ningún archivo seleccionado.

Al abrirlo, intentaré identificar JSON o texto UTF-8 válido. Un formato binario desconocido no se modificará.

2. Revisa el contenido

Edita con cuidado. Solo se habilita la descarga cuando el contenido puede volver a validarse según el tipo identificado.

Contenedor ZIP detectado — solo lectura

La exportación SDroiMod se ha observado como ZIP con entradas cifradas de slots. Aquí solo se listan metadatos del directorio ZIP; no se descifra, modifica ni recompila el guardado.

No se reconoce el formato interno

El archivo parece binario, comprimido o codificado. No intentaré cambiar valores por búsqueda/reemplazo: eso podría corromper tu partida. Abajo solo muestro una vista hexadecimal limitada; no equivale a descifrar ni a interpretar el guardado.

Estado y límites

  • La APK exacta indica que .sdroimod contiene un ZIP con entradas slot0.player a slot2.player cifradas; la clave y el contenido interno aún no están verificados con un archivo real de muestra.
  • La página no afirma poder editar dinero, puntos de habilidades, logros o slots: esos campos solo se podrán exponer cuando se identifiquen en un formato real.
  • Guarda el original aparte. Una descarga editada no debe reemplazar tu único backup.
  • La compatibilidad del archivo resultante con Magic Rampage no está probada hasta importarlo en una copia del juego.
  • Los datos cifrados no se envían ni se editan: todavía no se implementa el descifrado ni la recompilación.
¿Qué se podrá habilitar después?

Con un archivo de muestra (idealmente uno exportado por el juego), compararíamos estructura, cabecera, compresión/cifrado y checksum; después se añade un parser explícito con límites y pruebas de ida y vuelta. No se supone ni se inventa un algoritmo.

Esta herramienta corre localmente en el navegador. No es una herramienta oficial de Asantee Games ni una garantía de que un guardado modificado funcione.
