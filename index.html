SDroiMod Save Editor

Abre una copia exportada por el juego, revisa y modifica únicamente monedas, oro y nivel del bloque character. Luego descarga un .sdroimod nuevo.

Procesamiento local: el archivo se procesa en esta pestaña y no se envía a ningún servidor. Esta web es pública; usa copias, conserva el original y prueba el archivo nuevo en una partida desechable. El descifrado y reconstrucción se verifican localmente, pero no se garantiza que el juego acepte modificaciones.

Alcance y límites

  • Solo habilita character.gold, character.coins y character.level cuando aparecen una sola vez y como enteros decimales.
  • El texto descifrado conserva el formato y solo se reemplazan los tramos de los valores elegidos; los slots no editados conservan su contenido descifrado.
  • La salida ZIP se reconstruye y comprueba con CRC, y cada slot se vuelve a descifrar para confirmar igualdad exacta con el texto que se va a exportar.
  • No edita logros, inventario, gemas, habilidades u otros atributos. No se ha probado importación del archivo modificado dentro del juego.
  • AES-ECB no autentica datos. CRC detecta daños accidentales, no garantiza legitimidad ni compatibilidad.
Privacidad y seguridad

GitHub Pages sirve esta página; el contenido seleccionado no se sube. La página no usa telemetría ni llamadas de red. Revisa la versión y el código antes de usar datos que te importen; extensiones o software del dispositivo pueden tener acceso a archivos locales.

No oficial. No reemplaces tu único respaldo con el archivo generado.
