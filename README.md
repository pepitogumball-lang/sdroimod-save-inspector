# SDroiMod Save Inspector (prototipo)

Este sitio estático procesa archivos completamente en el navegador. No sube guardados ni tiene backend.

## Alcance actual
- Abre archivos de hasta 50 MiB.
- Reconoce JSON/texto UTF-8 para lectura y descarga como copia editada.
- Muestra una vista hexadecimal limitada si el formato es binario desconocido.
- **No** desofusca ni recompila `.sdroimod` ni garantiza compatibilidad con el juego.

No hay evidencia verificable del formato interno `.sdroimod` en el repositorio ni en las referencias públicas consultadas. No sustituyas tu guardado original.
